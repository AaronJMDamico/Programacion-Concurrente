1) En una oficina existen 100 empleados que envían documentos para imprimir en 5 impresoras
compartidas. Los pedidos de impresión son procesados por orden de llegada y se asignan a la primera
impresora que se encuentre libre. Resuelva el mismo problema anterior pero ahora usando PMS.

chan documentoEnviado(int, text)
chan documentoImpreso[100]()

Process Empleado [id: 0..99] {
	text doc

	send documentoEnviado(id, doc)
	receive documentoImpreso[id]()
}

Process Impresora [id: 0..4] {
	int idEmp = ?
	text doc

	while true {
		receive documentoEnviado(idEmp, doc)
		// imprime el documento
		send documentoImpreso[idEmp]()
	}
}
